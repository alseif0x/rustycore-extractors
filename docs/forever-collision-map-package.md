# Closed collision map package on disk

The optional Linux `collision::assemble::staged::package::assemble` consumes the
actual selected-VMO/world owner and a fresh private map-bundle Spool. No supplied
placements, selected names, models or proofs can construct its completed owner.
It completes M2 bounds from the closed source catalog, keeps supplied WMO bounds
and calls the existing map builder once per complete map. Selected models remain
the original pre-ID-dedup placement/list union; no dependencies are reacquired.

Private RCEPKG1 envelopes bind map/effective parent, complete native tree and
ordered dir_bin proof, unique spawn count and exact sorted tile payload/index
spans. All reserved bytes and complete extents are checked. Borrowed readers
validate the tree, complete proof ordering and each own payload/index association.
Parent-only tiles retain the child index and use the first present payload in
the actual effective-parent chain. A mismatch is terminal; no farther repair or
extractor immediate-parent-cache substitution occurs. Parent validation keeps
one copied child bundle and one borrowed ancestor, with separate bounded scratch.

The retained world/store/compact/Data/topology, full placement reservation and
VMO catalog remain charged. Two map-repository descriptor ceilings, fixed guard,
actual map/tile capacities, complete inputs, placements and builder scratch/output
overlap are admitted independently. The 2 GiB logical ceiling and every component
ceiling only decrease. A smaller package cap also reduces the older VMO reader's
headroom through an explicit conservative reservation. Complete bundle checks,
all own-association scans, inherited comparisons and model reads share a cumulative
validation budget; ancestor steps and BIH work have separate bounds. These are
logical admission/work counters, not allocator/RSS or all CPU operations.

The completed inventory preserves root dtree/exact-name VMO and nested native
map/tree/tile/index names. Metadata enumeration performs no body I/O. `visit`
reads each VMO and each complete map once, borrowing every map artifact from that
one read. Callback heap allowances cover retained caller state. Uninvoked captures,
readers/buffers, rejected returned values and the whole owned visitor drop before
final independent RAW/placement/VMO/map guards. Typed causes survive; all failures
poison the owner. Publication, resume and cleanup are caller responsibilities.

Existing v1 source/read/disk/reload and same-mount limits are unchanged; they can
reject a large world. Completed owners retain recorded client/store facts and
verified private bodies, not a live-client atomic snapshot. Product integration
must retain and recheck its actual LocalStore before final Run completion. No
server activation, real model/world acceptance or product distribution is added.
