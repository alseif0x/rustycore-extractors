# Private authenticated spooled world owner

`linux-private-authenticated-spooled-world-v1` consumes the same successful
spooled GameObject startup, reads complete authenticated Map, LiquidMaterial and
LiquidType through its original LocalStore, and invokes the spooled shared
runner with one collector. The scoped source passes 387 collision tests per
Linux debug/release profile, including 19 new world-owner tests. Its source
union with the v7 navigation/framing foundation passes 2,391 synthetic tests
per profile across 41 targets (22 ignored), Linux/GNU-Windows all-target Clippy
and both GNU-Windows compilation profiles. This optional library does not
change the product driver or establish real input, native CASC routing,
full-world extraction, runtime or distribution acceptance.

## Shared preparation and ownership

The original resident world and spooled owner use one private preparation
implementation with typed collector ledgers. Closed readers, physical direct
prefix, Map materialization, ordered liquid copies and missing-source insertion
remain the same. Conservative decoder allowances, actual string/vector/graph
capacities and topology creation overlap retain the existing downward ceilings.
The resident public API and error enumeration remain supported.

The caller's owned Sink must enforce its explicit retained-heap allowance. That
allowance is charged before Map preparation, survives lookup changes, and moves
into the placement Session without a release gap or a second charge. Successful
Session finish drops the actual Sink, caches and ID storage before releasing
their reservations. Source buffers/parsers and the caller-owned Store remain
separately charged. These are logical admission capacities, not RSS or every
allocator/CPU operation.

A failed lookup transition retains the original collector until the owned Sink
has been destroyed and both source and spool guards have run again. Pure errors
likewise preserve their cause through a final post-destruction check. Changed
has diagnostic priority. The completed world owns its startup Data and validated
Topology; their exact combined reservation remains in the completed payload
repository, including later RAW reloads. No public arbitrary uncharge, forged
Topology or partial Completed is exposed. Temporary rows, strings, graph and
lookup vectors drop before their exact reservations are released.

## Remaining completion gates

WDT and parent-cache inventories remain bounded resident components. The same
4,096 cumulative read ceiling covers startup DB2, world DB2, WDT, ADT and model
dependencies; this addition does not raise it or claim scalable full-map output.
Disk-backed inventories, versioned realistic policies, selected VMO/map assembly,
product integration remain required. Real mandatory
DB2 acquisition, complete model/world inventories, native/reader/runtime checks
and Linux/Windows distribution retain their separate gates. Every placement
Sink output is provisional; this API performs no product publication or resume.
