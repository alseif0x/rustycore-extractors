# Authenticated disk-inventory collision world

`linux-private-authenticated-disk-world-v1` is an optional Linux library owner
with scoped synthetic acceptance. It consumes successful GameObject startup
and two fresh typed WDT/cache inventories. Closed Map, LiquidMaterial and
LiquidType acquisition, direct-prefix graph construction and topology snapshots
use the same established model collector. Cached models retain their original
empty-lookup output; only newly acquired models see the prepared liquid lookup.

The complete collector and both inventory heap ceilings must fit the explicit
downward-only 2 GiB combined logical ceiling before DB2 acquisition. Each disk
inventory also obeys the existing 256 MiB component cap and exact reduced
parser/cache policies. No component ceiling is increased. Source/parser,
rows/strings, liquid vectors and graph reservations stay in the collector.
The owned Sink is charged before preparation and its exact charge is moved
through a private transfer into the placement Session without a release gap
or double charge. Inventories stay disjoint and separately counted. Returned
replay bytes have their own pre-I/O collector allowance through callback/drop.
These conservative reservations are not RSS, exact allocator usage or all CPU
work. Completed Data/topology remain charged through later RAW reloads.

WDTs, globals, maps and tiles retain the declared physical/depth/x-y order of
the [disk runner](forever-collision-disk-run.md). Empty own tiles block fallback;
only successful own parent tiles enter caches. Globals and inherited tiles are
never cached for descendants. Sorted existing parent keys skip absent ranges
while preserving lazy inactive-parent failure at the first missing cell.

All preparation transitions check actual acquired source/model guards and both
inventories independently. Every failed path destroys its returned values and
owned Sink before the final checks. Successful run finish also destroys the
actual Sink before those checks. Typed original causes survive independently
observed changes, which have diagnostic priority. No failed call returns a
Completed token. Protected directory anchoring remains object identity, not
authentication of unread directory contents or an atomic snapshot.
